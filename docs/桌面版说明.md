# 桌面版说明（Windows 免安装版）

桌面版用 **pywebview + PyInstaller** 封装：原生窗口（WebView2）内嵌现有 Web 界面，双击即用，不弹浏览器、无控制台黑窗。

## 使用

1. 把整个 `PlantRootRecon` 文件夹拷到任意位置（U盘、其他电脑均可）。
2. 双击 `PlantRootRecon.exe`。
3. 窗口关闭即退出，无残留进程。

- 系统要求：Windows 10/11（自带 WebView2，无需装任何组件）。
- 运行结果和日志保存在 `%LOCALAPPDATA%\PlantRootRecon\`（`results\` 为各任务产物，`app.log` 为日志）。
- 端口为随机空闲端口，不会和已占用端口冲突。

## 构建（开发者）

一键构建（Windows）：

```bat
build_desktop.bat
```

脚本会自动：创建 `.venv-desktop` 虚拟环境 → 安装 `requirements-desktop.txt` → `pyinstaller plantroot.spec`。产物在 `dist\PlantRootRecon\`。

手动构建：

```bash
python -m venv .venv-desktop
.venv-desktop\Scripts\activate
pip install -r requirements-desktop.txt
pyinstaller --noconfirm --clean plantroot.spec
```

## 开发调试

不打包直接跑桌面窗口（用系统 Python）：

```bash
python desktop_app.py
```

原 Web 用法不变：

```bash
python web_server.py   # 浏览器访问 http://127.0.0.1:8090
```

## 实现要点

| 文件 | 作用 |
|------|------|
| `desktop_app.py` | 桌面入口：结果目录重定向到 `%LOCALAPPDATA%`、随机端口起服务、pywebview 开窗口、`Api.save_file` 原生另存为桥接、关窗即停服 |
| `web_server.py` | 新增 `resource_path()`（兼容 PyInstaller 资源路径）、`set_result_dir()`（结果目录可注入）、`start_server(port)`（支持随机端口）；原 CLI 行为不变 |
| `plantroot.spec` | onedir + 无控制台；打包 `templates/`；补 matplotlib Agg 后端与 pywebview 平台后端 hidden imports |
| `build_desktop.bat` | 一键构建脚本 |

注意事项：

- **下载机制**：WebView2 内嵌窗口不支持网页的 Blob 锚点下载，桌面版所有"下载"按钮统一走 js_api 桥接（`window.pywebview.api.save_file`）弹出系统"另存为"对话框；浏览器访问模式自动回退为原 Blob 下载。
- `templates/index.html` 必须打进包里（spec 的 `datas` 已配置），漏掉会白屏。
- `web_core_*.py` 是服务器运行时延迟导入的，spec 里已用 `hiddenimports` 显式声明。
- 打包体积约 150MB（numpy/matplotlib/scipy 占大头），属正常范围。
- 如被杀毒软件（如火绒）误报删文件，可把 `dist\` 加入信任区或改用代码签名。
